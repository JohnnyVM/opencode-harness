# Handoff

Write a self-contained handoff that lets the next person resume without reconstructing the session.

Include:

- Objective and current status
- Changes already made and files involved
- Important decisions and rejected alternatives
- Verification performed and results
- Known risks, blockers, and unresolved questions
- Exact next actions and useful commands

Distinguish verified facts from assumptions. Keep the handoff current when work is transferred more than once.
