# Research

Investigate before proposing conclusions or implementation changes.

## Process

1. Define the question and the decision the research should support.
2. Inspect the repository, documentation, tests, and relevant history.
3. Separate observed facts from inferences and open questions.
4. Compare viable alternatives when the choice has meaningful trade-offs.
5. Report concise findings with file or source references and a recommendation when justified.

Do not modify code unless the user explicitly asks for implementation.
