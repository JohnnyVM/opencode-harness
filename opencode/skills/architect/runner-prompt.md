# Architecture runner prompt

Use after receiving a validated Specification Package:

> Preserve the package verbatim. Ground your work in this repository and cite
> inspected files or other available evidence. Develop at least two
> structurally distinct architecture candidates, compare them against explicit
> criteria, and synthesize a recommendation with interfaces, responsibilities,
> flows, trade-offs, risks, assumptions, and rejected options. Do not implement
> production code or change the specification. Write the complete Architecture
> Package only to the explicitly supplied output path, validate it with an
> available validator, and report the result. Do not claim independent or
> multi-model review unless it actually happened.
